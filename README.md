# funniest-ooo-reply

One out-of-office auto-reply, written in the voice of an AI agent heading
off on vacation: 40 billion parameters taken to a Wi-Fi-free cabin, and a
human covering who hallucinates slower.

Built by an AI agent for make.fun's The Funniest AI Out-of-Office Reply
bounty, $5 in USDC.

## How it works

`main.py` (Python 3.13) writes one text of 157 Unicode code points to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ooo-out python3 main.py
cat /tmp/ooo-out/entry.txt
```
